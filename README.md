## How to publish this page

1. Create a new public GitHub repo, e.g. `microsoft-certifications`.
2. Upload `microsoft-certifications.html` and rename it to `index.html`.
3. Go to **Settings → Pages**, set source to the `main` branch, root folder, and save.
4. GitHub gives you a live URL like `https://<your-username>.github.io/microsoft-certifications/`.
5. Paste that URL into LinkedIn: **Profile → Add profile section → Featured → Add a link.**
